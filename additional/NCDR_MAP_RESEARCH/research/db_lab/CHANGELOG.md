# Changelog

## 1.4.0 — 2026-10-06

- Added deterministic `NCDR_TASK_PLAN_V1` YAML authoring with a vendored SafeLoader, strict schema and operation registry checks, named byte patterns, explicit scopes, controls, references, conditions, report bindings, outputs, and revision SHA metadata.
- Routed strict plans around natural-language compilation and added scope and positive-control dry-run gates, per-step execution logs, localized preview details, and an experimental label for natural-language task compilation.
- Clean-built the native macOS application for Intel x86_64 with dynamic 1.4.0 bundle versioning.

## 1.0.0 — 2026-10-06

- Added a native SwiftUI/AppKit Intel macOS workstation shell backed by the existing Python research engine.
- Added read-only artifact cataloging, SHA256 and entropy fingerprints, ISO-9660/CUE inspection, conservative firmware-container recognition, PE metadata, string/constant search, and directory byte-diff support.
- Added SQLite artifact provenance and knowledge bases, task manifests, dated isolated runs, run logs, report and ChatGPT package generation, and Finder package reveal.
- Added the project-only `PROJECT_INVENTORY` task. It does not launch compression brute force or decoder reconstruction.
- Preserved the established DB_0 reader, road research, firmware notes, and earlier DB_0 lab reports.
# 1.1.0

- Added complete record-level controlled experiment diffs and hash-based identical-output grouping.
