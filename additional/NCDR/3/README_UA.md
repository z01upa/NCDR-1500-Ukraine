# NCDR - вузьке виправлення A01 NameError

Цей пакет тільки для збою `AUTO_MISSION_EXEC_A01_*: NameError: name 'available_models' is not defined`.

1. Перед встановленням у Manager призупиніть або зупиніть **бездіяльний** Worker. Не зупиняйте активну OSM-конвертацію чи інші задачі.
2. Запустіть `START_A01_FIX.cmd`. Скрипт шукає активний репозиторій в `Documents\Codex\2026-10-25\new-chat-2\work\NCDR_MAP_RESEARCH`. Якщо його там немає, виходить без змін; альтернативний шлях можна передати аргументом.
3. `PATCH_INSTALLED` - збережено резервні копії, пройдено перевірку імпорту, однократного повернення заблокованої A01 та регресійний тест планування. Після цього запускайте Worker звичайним способом. `NO_PATCH_OR_ROLLED_BACK` - код не змінено або відновлено з backup.
4. Після перезапуску Worker має автоматично повторити тільки заблоковану A01-задачу з цим точним NameError (одну спробу), якщо збережена помилка справді відповідає умовам. Коли причина інша, завдання залишається заблокованим.

**Обмеження:** цю версію випробувано на наявному знімку коду та тестовій симуляції NameError, але не на поточному Lenovo. Вона НЕ робить Writer готовим і НЕ ремонтує решту 48 WAITING_CODEX. Якщо форма функцій у Вашій новішій версії інша, скрипт відмовиться від патча. Оригінальні CD, OSM/PBF і робоча SQLite не змінюються встановлювачем; оновлюються лише два Python-файли в `src/agent`.
