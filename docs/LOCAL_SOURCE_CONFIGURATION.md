# Локальний корінь вихідних даних

Репозиторій містить код і звіти, але не оригінальні карти та firmware. Щоб запустити наявний read-only аналіз локально, задайте корінь зовнішнього набору через `NCDR_SOURCE_ROOT`.

PowerShell:

```powershell
$env:NCDR_SOURCE_ROOT = 'D:\NCDR-Original'
```

macOS/Linux:

```sh
export NCDR_SOURCE_ROOT="/path/to/NCDR-Original"
```

Значення — локальне налаштування сеансу, його не слід комітити. За відсутності змінної код використовує корінь checkout; оригінальні входи там не встановлені.

Історичні результати могли містити абсолютні шляхи до робочих каталогів. У публікаційному snapshot їхні персональні префікси замінено на `${NCDR_SOURCE_ROOT}`, `${NCDR_WORK_ROOT}`, `%USERPROFILE%` або `$HOME`. Це позначки походження в даних, а не автоматично розгортувані шляхи.
