# Наявні блокери - адресні маршрути виправлення

Наведені імена відомі зі звіту від 26.10.2026; реальний SQLite перед внесенням правок перевірити повторно.

| Заблоковане | Категорія | Автоматична відповідь | Заборона |
|---|---|---|---|
| `AUTO_OSM_NATIONAL_CONVERSION_01` | OOM або TIMEOUT | A02 -> D01 -> D03 -> D04 -> D07 з контрольними точками. Два повідомлення про причини не плутати | Не повторювати повний імпорт або просто збільшувати timeout |
| `AUTO_SCHEDULED_PROBE_IL_*` | `KeyError IL` | Виправити мапінг суфіксу, тест на наявний корпус, повторити тільки конкретну задачу | Не позначати `PASS`, не підміняти невідомі поля |
| `AUTO_SCHEDULED_PROBE_IOF_*` | `KeyError IOF` | Аналогічно попередньому, обмежений repro | Не виконувати недозволений script |
| `AUTO_RESEARCH_FOLLOWUP_*` | `ScriptRejected` | Визначити схему відповіді, ліміт скрипту, AST allowlist; підготувати Capability Request | Не запускати довільний код |
| `AUTO_RESEARCH_BOOTSTRAP` | `ScriptRejected` | Ізольований repro, Codex patch, regression test | Не відключати sandbox |
| `F1_TARGET_COMPATIBILITY` | `WAITING_EXTERNAL` | Усі незалежні інженерні етапи продовжити, зібрати мінімальний запит на фото моделі/ревізії | Не вигадувати назву пристрою |
| `F3_WRITER` | `RESEARCH_BLOCKER` | B11 -> C01 -> C02, поступово лише для доведених структур | Не вимагати фізичного NCDR для експериментального writer |
| `F4_OSM_PIPELINE` | Хибна залежність від writer | D01..D08 окремо, інтеграція тільки E01 після C04 | Не блокувати OSM-ingest через F1/F3 |

Правило: unblock status знімається лише після evidence + test. Planner має право перейти до іншої незалежної задачі, але не рахувати тупикове повторення як прогрес.
