# Редактор особистих місць

Запустіть `NCDR_POI_Editor.pyw` подвійним клацанням або з кореня проєкту виконайте:

```powershell
pythonw -m src.poi_editor
```

Редактор і Virtual CID використовують спільну локальну SQLite-базу в `%LOCALAPPDATA%\NCDR Ukraine\personal_poi.sqlite`. Можна вказати інший файл параметром `--db`. Назва, координати й категорія перевіряються та зберігаються локально; підтримується JSON імпорт і експорт.

Ця база є внутрішнім проміжним шаром. Редактор не записує зміни до оригінальних NCDx носіїв і не заявляє сумісність із форматом Opel.
