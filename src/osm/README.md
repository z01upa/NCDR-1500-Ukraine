# OSM pipeline (внутрішній формат)

Внутрішній конвертер працює окремо від недоведеного NCDx writer. Він завантажує датований регіональний OSM PBF, фільтрує географічне вікно Кривого Рогу, конвертує дороги, назви, адреси, POI та вузли в SQLite і виконує експериментальну маршрутизацію.

Збірка: `python -m src.osm.build_kryvyi_rih --source geofabrik`. Повторна збірка не перезаписує наявні джерело чи базу: збережіть новий часовий зріз під окремою назвою.

Джерело зберігається в `data/osm/source.json`; поточний upstream content timestamp і хеші зазначені там. Фільтр використовує географічну рамку, а не підтверджений адміністративний полігон. Експорт relations і обмеження поворотів поки не імпортовані; маршрути показуються як експериментальні. У застосунку завжди показано атрибуцію OpenStreetMap / ODbL.

Вихідні таблиці OSM та майбутній експорт NCDx розділені через `src/adapters/ncdx_adapter.py`. Поки семантика записів не доведена, адаптер явно відмовляється імпортувати чи експортувати NCDx.
